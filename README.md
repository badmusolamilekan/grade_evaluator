Grade Evaluator

Project Description

The Grade Evaluator is a simple web-based application designed to calculate a student's grades across various subjects. Users can input their scores for Mathematics, English Language, Civic Education, and Biology, and the application will process these inputs to provide results. The user interface has been designed for clarity and ease of use, featuring a modern and professional aesthetic powered by Tailwind CSS.

Usage

1.
Enter the scores for Mathematics, English Language, Civic Education, and Biology into their respective input fields.

2.
Click the "Calculate Results" button.

3.
The calculated result (or an error message if inputs are missing) will be displayed below the button.

Technologies Used

•
HTML5: For the structure of the web page.

•
Tailwind CSS: For styling and responsive design.

•
JavaScript: For interactive functionality and grade calculation (evalution.js).
